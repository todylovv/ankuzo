# Стрим-инструменты Ankuzo

Состав и команды проверки: [карта проекта](../docs/project-map.md). Это исходники работающих сервисов, без рабочих конфигураций и данных.

## OBS

Пульт управляет отдельными профилями начала/перерыва, игровым оверлеем, непрозрачной заглушкой миникарты с чатом, счётчиком мата и общим источником оповещений. Начало/перерыв имеют холст1920×1080. Размер малых виджетов выдаётся пультом; источник фоллоу/подписок/донатов560×440. Статические изменения кода требуют обновления браузерного источника, а настройки приходят через API без новой ссылки.

Фоллоу: одна вращающаяся карта, красная нить и ник. Платная подписка: веер из трёх карт, светлый центральный туз, золотая нить, Tier/месяцы/количество подарков. Настройки и MP3/WAV/OGG до5МБ независимы. Предпросмотр локален пульту; отдельный тест в OBS виден в эфире. У reduced-motion статичная композиция; в ожидании источник прозрачен и не анимируется.

Одно OAuth-приложение Twitch получает moderator:read:followers и channel:read:subscriptions. EventSub channel.follow v2 и channel.subscribe/channel.subscription.message/channel.subscription.gift v1. Продление показывается, когда зритель делится им в чате. Подарочный набор показывается один раз с дарителем и количеством. Секреты хранятся на сервере с правами0600 и не выдаются по OBS-ссылке. DonationAlerts подключается отдельно через OAuth и Centrifugo; рабочие ключи задаются только в защищённом пульте.

Микрофон передаёт PCM worker-сервису, который загружает Whisper small и распознаёт русский язык. Модель и runtime-состояние не входят в Git; worker доступен только в приватной Docker-сети. При его отсутствии остальные сцены продолжают работать.

## Конфигурация и запуск

`compose.example.yml` — пример для **новой** установки, не команда переноса существующего production. Перед переносом запланируйте остановку записи/таймеров/воспроизведения и сохраните все приватные данные. Пример не меняет существующие сервисы автоматически.

1. Скопируйте `runtime.env.example` в `runtime.env`, `music.config.example.json` в `music.config.json`. Укажите свой домен.
2. Создайте внутренний случайный ключ, например `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"`. Впишите его в ANKUZO_CONTROL_KEY и adminKey музыкальной конфигурации; не публикуйте ключ.
3. Создайте `obs/data`, `music/data`, `music/vk-profile`, `speech/models`. Музыке и VK нужен UID1000 с доступом к своим данным/конфигурации; модели речи — UID10001. Конфигурации ограничьте правами600, приватные каталоги700. OBS-контейнеру нужен доступ к своему тому данных.
4. Docker-сеть edge должна существовать: `docker network create edge` для новой установки. Проверить пример: `docker compose -f compose.example.yml config --quiet`.
5. Запуск: `docker compose -f compose.example.yml --profile speech --profile vk up -d --build`. Речь и VK — опциональные профили. Модель речи скачивается отдельно при первом старте.
6. Настройте HTTPS-прокси Caddy и вход администратора. Публичные личные пути `/obs/view/music/*` направляются в музыку17223 с сохранением пути; `/obs/view/*` — в OBS17222 с удалением `/obs`. Административные `/obs/music/*` идут в музыку с сохранением пути, `/obs/*` — в OBS с удалением `/obs`, **после Basic auth**, с внутренним заголовком `Authorization: Bearer <ключ>`. Конкретные музыкальные пути обрабатываются раньше общего OBS-маршрута. Worker17223 и VK17225 не публикуются в интернет. Конфигурация host-Caddy с чужими сервисами/хэшами паролей в этот репозиторий не копируется.

Пульт OBS проверяет Host и Origin домена. При edgeAuth=1 без прокси-авторизации администраторские страницы закрыты. Вход OBS не использует пароль внутри личной ссылки. Не отключайте эту проверку ради публикации.

Музыкальный контейнер включает ffmpeg, yt-dlp и yandex-music; VK использует отдельный Chromium с постоянным приватным профилем. Подробнее: [музыка](music/README.md). Dockerfile версий зависимостей сохранены из работающей установки; обновление провайдеров требует отдельной проверки реальных пользовательских ссылок.

## Донаты DonationAlerts

В пульте оповещений выберите «Донат · красная печать» (`/obs/follow-control.html?kind=donation`). Красная печать раскрывается вокруг суммы в исходной валюте; ниже появляются ник и до трёх строк сообщения. Настройки длительности/подписи/вращения/громкости и аудио MP3/WAV/OGG независимы от Twitch. Все три вида идут в одной очереди через прежнюю личную ссылку источника560×440. Предпросмотр не отправляет событие в эфир.

Для настоящих донатов один раз зарегистрируйте приложение на https://www.donationalerts.com/application/clients. Redirect URI: `https://ankuzo.online/obs/api/follow/donationalerts/callback` (для своей установки копируйте фактический адрес из пульта). Сохраните Client ID и Client Secret в разделе DonationAlerts, затем нажмите «Подключить DonationAlerts» и разрешите доступ. Секрет не нужно передавать в чат или добавлять в Git. Пульт показывает аккаунт и фактическое состояние realtime-соединения.

Используются только `oauth-user-show oauth-donation-subscribe`. История донатов не загружается; события за время отсутствия соединения могут быть пропущены. Сервер подключается к официальному Centrifugo, подписывается только на канал авторизованного пользователя, обновляет access token, восстанавливает соединение с задержкой и хранит последние1000 идентификаторов для защиты от повторов после перезапуска. Ручной тест отмечен отдельно и виден в OBS. Прикреплённые аудиосообщения зрителей загружаются с HTTPS-доменов DonationAlerts без перенаправлений, проверяются по содержимому и длительности и воспроизводятся после короткого сигнала. Лимиты:5МБ и120секунд. Сцена и общая очередь учитывают длительность записи. В пульте есть отдельные включение/громкость голоса и файл для предпросмотра. Записи находятся только в ограниченном кэше памяти, не сохраняются в Git или на диск. Если запись недоступна, сцена показывает это и продолжает обработку событий.

Файлы `donationalerts-private.json`, `donationalerts-seen.json`, `donation-settings.json`, `donation-audio.json` и `donation-audio.bin` находятся в приватном каталоге данных OBS. Приложение/токены сохраняются атомарно с правами0600; ни они, ни email/платёжные данные не попадают в публичный SSE. DonationAlerts здесь используется для отображения уведомлений; приём платежа остаётся у DonationAlerts.

При первом развёртывании обновите браузерный источник OBS, чтобы он загрузил новую версию JavaScript. Пересоздавать источник или менять личную ссылку не требуется. Дальнейшие изменения настроек и звука применяются через пульт.

Парсер длительности аудио собран в `obs/app/vendor/audio-metadata.cjs` из закреплённого `music-metadata`12.2.3; рабочему серверу не требуется npm install. Для обновления на сборочном сервере: `npm --prefix stream-tools/obs ci`, затем `npm --prefix stream-tools/obs run build:voice-metadata`. Лицензии зависимостей — `obs/app/vendor/LICENSES.txt`. Сгенерированный файл исключён из lint; исходный код и прежние правила React проверяются как раньше.
