# Ревью фоновой музыки

Объём: сравнение с опубликованным плеером до этого этапа; Queue, Media, Background, Яндекс SDK bridge, HTTP-маршруты, пульт, OBS, личный монитор и документация. Проверены сохранность Twitch-заказов, приоритет очереди, поколения источников, перезапуск, границы administrator/viewer, входные ссылки, DOM-вставки и независимость громкостей.

Исправленные находки:

- Смена источника во время загрузки обложки оставляла устаревший item и могла отклонить media worker. Проверка существования item после await; падающая серверная регрессия теперь проходит.
- Последовательный feedback Яндекса задерживал подготовку песен при медленном API. Обратная связь вынесена в отдельную ограниченную очередь; серверная регрессия подтверждает независимость подготовки.
- FLIP всего плеера накладывался на громкости в промежуточном кадре. В пульте анимируется измеренная высота одного превью; соседние элементы следуют нормальному потоку. Исправленный кадр просмотрен.
- Перерисовка очереди теряла клавиатурный фокус. Фокус восстанавливается на доступной кнопке того же заказа.

Проверки: 30 серверных автоматических тестов, проверки синтаксиса, реальные браузерные сценарии очереди/фона/двух громкостей, каталог действующего аккаунта, пополнение волны, desktop/mobile и reduced-motion. Протоколы в design/. Секреты в исходники и скриншоты не включены.

Рабочее обновление сохранено с резервной копией backup-background-20261023T110829Z. Хеши ключевых исходников рабочего сервиса совпали с проверенным кандидатом. Один настоящий Twitch-заказ сохранён с прежними redemption/refund/settled, стоимость 500, Twitch/Яндекс/VK подключены. HTTPS: защищённые пульты 401 без пароля, viewer 200, media range 206, запрет viewer на коллекцию 403. Внутренний корневой маршрут OBS проверен отдельно: внешний /obs/ передаётся Caddy в него.

Нерешённых блокирующих находок в проверенном объёме нет. Известные ограничения: для настоящего зачисления возврата нужен отдельный тестовый зрительский заказ; Spotify использует только явно включаемый поиск версии YouTube; полный пользовательский VK-видеоклип не проверен. Refresh-token Яндекса автоматически не обновляется. Отказ или изменение API музыкальных сервисов требует сопровождения.
