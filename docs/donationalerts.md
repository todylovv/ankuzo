# DonationAlerts: контракт оповещений

Интеграция использует официальные [OAuth/REST/Centrifugo API](https://www.donationalerts.com/apidoc) и JSON-протокол Centrifugo v2. OAuth scopes: `oauth-user-show oauth-donation-subscribe`. Endpoint провайдера, канал и callback задаёт сервер; произвольные внешние URL не принимаются.

## Совместимость

Существующий источник `follow.html`, личная OBS-ссылка и маршруты `/api/follow/*` сохранены. В публичный SSE-снимок добавлены профиль `donation: { settings, audio: { available, version } }` и события `kind: "donation"`. Предыдущие `follow`/`subscription` продолжают работать. Обновите код браузерного источника один раз после установки; новые настройки приходят без изменения ссылки.

Донат содержит общие `id/name/startsAt/endsAt/message/motion/kind` и поля `amount` (положительная десятичная строка, два знака после точки), `currency` (`RUB/USD/EUR/BYN/KZT/UAH/BRL/TRY`), `donationText` (до500символов). Сумма отображается в исходной валюте без конвертации. Сообщение выводится как текст, максимум три строки. Аудиосообщения имеют `messageType: "audio"` и, если запись доступна, `voice: { id, durationMs }`. URL провайдера не передаётся в SSE. Для загрузки допускаются только HTTPS-домены DonationAlerts, без redirect, максимум5МБ/120секунд. Парсер проверяет формат и длительность; кэш памяти ограничен32МБ. Ошибка загрузки обозначается `voiceUnavailable`.

Одна очередь ограничена30событиями, интервал между ними500мс. Аудиосообщение увеличивает слот до максимума из базовой длительности и длительности записи плюс2600мс; голос начинается через1800мс, останавливая короткий сигнал. Настройки `voiceEnabled`/`voiceVolume` независимы от сигнала. Выключение профиля удаляет только его события. Общая очередь и звук не накладываются. Приватный статус содержит число отклонённых из-за переполнения оповещений `dropped`. Очередь находится в памяти; рестарт сервиса её очищает. Для оповещений DonationAlerts сохраняются последние1000идентификаторов с ID аккаунта, поэтому повторная доставка после reconnect/restart не дублирует недавние донаты. История отключения не запрашивается; гарантии восстановления пропусков нет.

## Административные маршруты

Все пути ниже имеют префикс `/obs/api/follow/` на опубликованном сайте. Нужен вход в защищённый пульт. POST также требует same-origin, JSON и `X-Ankuzo-Control: 1`.

| Маршрут | Назначение |
| --- | --- |
| `GET status` | Общий приватный статус, включая `donationalerts: { configured, clientId, account, connection, error, callbackUrl }` |
| `POST settings` | Общие настройки с `kind: "donation"`; прежние поля и ограничения сохранены |
| `POST audio` | Отдельный звук с `kind: "donation"`; MP3/WAV/OGG до5МБ или `remove: true` |
| `GET voice?id=<id>` | Приватные проверенные байты записи; доступно по личной viewer-ссылке, GET/HEAD/Range, без параметра URL |
| `POST test` | Пример в настоящей очереди, с `kind/amount/currency/donationText/name`; опциональный `voiceData` — base64 файла до5МБ (POST до7МБ); виден зрителям |
| `POST donationalerts/app` | Сохранить `clientId/clientSecret`; сбрасывает авторизацию только DonationAlerts |
| `GET donationalerts/connect` | 302 на официальный OAuth с одноразовым random state на10минут |
| `GET donationalerts/callback` | Проверить state, обменять code, сохранить разрешение, 303 в пульт донатов |
| `POST donationalerts/disconnect` | Удалить разрешение аккаунта и ожидающие донаты; Twitch сохраняется |

Ошибки формата/настроек возвращают400с безопасным сообщением, слишком большой POST413, отсутствие авторизации401, запрещённый viewer/mutation403. Callback-ошибка показывает HTML с возвратом в пульт. Личная viewer-ссылка разрешает только существующие read-only потоки и звук; доступ к настройкам/OAuth закрыт. Секреты, access/refresh/socket/channel tokens и email не включаются в публичный SSE или административный статус.

## Эксплуатация

Проверка: `npm run test:obs`. Mock-тесты покрывают OAuth state/TTL/replay, права, канал и структуру Publication.data, дедупликацию после перезапуска, refresh без нового refresh_token, разные настройки/звук и совместную очередь. Живой аккаунт DonationAlerts подключается владельцем через пульт; успешные mock-тесты не означают фактической авторизации.
