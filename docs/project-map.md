# Полный комплект Ankuzo

Репозиторий объединяет сайт и исходники стрим-инструментов. Корень остаётся React/TypeScript/Vite-сайтом; переносить его в новую папку для сборки не требуется.

| Каталог | Назначение | Проверка |
| --- | --- | --- |
| `src/`, `public/`, `deploy/` | ankuzo.online, красный дым, карты, публичные данные, развёртывание сайта | `npm run lint`, `npm test`, `npm run build` |
| `stream-tools/obs/app/` | пульт, начало, перерыв, оверлей, миникарта/чат, счётчик мата, фоллоу, подписки Twitch и донаты DonationAlerts | `npm run test:obs` |
| `stream-tools/obs/tests/` | серверные тесты OBS, прав доступа, счётчика, OAuth/EventSub и аудио | входит в `test:obs` |
| `stream-tools/speech/` | Python/faster-whisper worker для распознавания микрофона | синтаксис Python; Dockerfile фиксирует версию зависимости |
| `stream-tools/music/` | музыкальная очередь, Twitch-награда, Яндекс, VK, музыкальный OBS-источник | `npm run test:music`, `npm --prefix stream-tools/music run check` |

`npm run test:all` выполняет тесты сайта, OBS и музыки. У OBS свой `package.json` с `type: commonjs`: его `timer.js` и CommonJS-сервер не должны наследовать `type: module` сайта. У музыки собственный ESM-пакет. OBS и тестам музыки не нужна установка npm-зависимостей; VK-sidecar получает Playwright через собственный Dockerfile.

## Рабочие адреса

- Сайт: https://ankuzo.online/
- Пульт сцен: https://ankuzo.online/obs/
- Фоллоу и подписки: https://ankuzo.online/obs/follow-control.html
- Донаты: https://ankuzo.online/obs/follow-control.html?kind=donation
- Музыка: https://ankuzo.online/obs/music/

OBS-ссылки персональные и выдаются пультами после входа. Их нельзя сохранять в README, issues или коммитах. GitHub Pages собирает только статический сайт; Node-сервисы OBS/музыки и Python worker работают на сервере за Caddy.

## Данные и секреты

В Git включены исходники, брендовые изображения/шрифты и тесты с имитацией провайдеров. Рабочие настройки пользователя, OAuth-токены, внутренние ключи, загруженные звуки, музыкальная очередь/медиа, cookies/профиль VK, файлы модели речи и реальные `runtime.env`/`config.json` исключены. Примеры конфигурации содержат только пустые поля и заглушки.

Для восстановления существующей установки отдельно нужен **приватный** бэкап каталогов данных и конфигурации. Без `obs-access.json` и музыкального `viewer.json` будут созданы новые личные ссылки; без OAuth-файлов сервисы потребуют повторного подключения. Не заменяйте рабочие данные пустыми примерами при обновлении кода.

## Снимок работающего кода

Сборка репозитория от 23 октября 2026 использует исходники активного сайта `/opt/ankuzo-mobile-20261014`, OBS `/opt/ankuzo-obs-scene-20261021/app`, speech-worker `/opt/ankuzo-speech-20261022` и музыки `/opt/ankuzo-music-20261023/app`. Это описание происхождения, а не новые обязательные пути установки. Старые архивы и кандидатные копии не включены.

Сервисы при сохранении в Git не перезапускались, рабочие очереди, счётчик и личные ссылки не изменялись. Интеграция DonationAlerts реализована; для настоящих событий требуется одноразовая настройка собственного OAuth-приложения и авторизация аккаунта в защищённом пульте. Подключение Twitch для фоллоу/подписок выполняется отдельно в соответствующем пульте; музыкальный пульт использует своё подключение для наград.
