# Работающие наброски нити

Запуск: `npm run dev`, затем `/prototypes/thread/`.

Три материала — шёлк, глянцевая эластичная нить и микроплетение — сравниваются на одинаковой геометрии. Поворот, толщина, увеличение ×2 и движение управляются на странице. Это отдельный прототип: основной сайт его не импортирует. Production-сборка публикует его по адресу `/prototypes/thread/` для сравнения вариантов.

Один WebGL-рендерер рисует три области; карта закрывает заднюю часть обвязки через depth test. Нить имеет объёмное сечение и нормали, замкнутую обвязку, свободные хвосты и небольшой узел. Фактура использует координаты по длине нити. Толщина в пикселях относится к плоскости карты при масштабе 1×. Увеличение честно отмечено в интерфейсе.

Это сравнение материала, а не готовая интеграция в пятиглавную сцену сайта. Проверены управление, лицевая сторона, поворот 90°/180°, увеличение и мобильная прокрутка. В паузе кадры не перерисовываются; скрытая вкладка останавливает движение.
